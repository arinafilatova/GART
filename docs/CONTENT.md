# Тексты и тестовые данные

Основные данные находятся в `assets/app.js` в функции `resetState()`.

| Что изменить | Где |
| --- | --- |
| «О нас» | Массив `content`, объект `id: 'about'`, поле `text` |
| Заголовок и описание Владимира | Объект `id: 'founder'`, поля `title` и `text` |
| Пример публикации СМИ | Объект `id: 'media'`, поля `title` и `text` |
| Партнёр | Объект `id: 'partner'`: название, описание поддержки, URL и логотип |
| Мероприятия | Массив `events` |
| Контакты | Экран `/contacts` в функции `publicPage()` |
| Реквизиты | Функция `donate()` |
| Ответы «Откуда вы о нас узнали?» | Массив `HEARD_FROM`; ответ в заявке хранится в `heardFrom` |

Блоки создателя и СМИ содержат вымышленные примеры. После замены на согласованные сведения отдельно уберите пометки «Тестовые данные» в функции `about()`. До этого их следует сохранить. Фотография основателя не добавлена: буква «В» — графический элемент, а не изображение реального человека.

Внутри открытого прототипа можно проверить изменение материалов через CRM. Эти изменения действуют только до перезагрузки и не меняют файлы репозитория. Для постоянных изменений отредактируйте исходный файл и загрузите новую версию в GitHub.
